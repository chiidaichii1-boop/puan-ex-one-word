## Entry

**Unsubscribed**

One word describing an ex: a former partner treated like a newsletter
you finally opted out of. No more updates, no more noise, no renewal.

## How it works

`main.py` (Python 3, standard library only) writes exactly that one
word to `entry.txt` in the output directory given by
`MAKEFUN_OUTPUT_DIR` (falling back to `/output`). It creates the
output directory if missing and never deletes it.

## Run

```sh
python3 main.py
```

The entry file is written to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` by default).
